## Reporting a Vulnerability  

If you discover a security vulnerability in this repository, please **do not open a public issue**.  

Instead, report it directly to **AfriNuts Export Security Team** at:  

📧 **AfriNutsExport2023@outlook.com**  

### What to Expect:  
- You will receive an acknowledgment within **72 hours**.  
- The team will provide status updates until the issue is resolved.  
- If accepted, fixes will be prioritized and released as soon as possible.  
- If declined, you will be notified with an explanation.  

---

## Responsible Disclosure  

We kindly request that all security researchers:  
- Report vulnerabilities privately before making any public disclosure.  
- Allow us a reasonable time to investigate and deploy fixes.  
- Avoid actions that could disrupt services or compromise user data.
